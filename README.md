# Demo Yvoty Café — portfólio do Michael (marca fictícia)

- `site/` — landing page (Vite + React + TS + Tailwind + Framer Motion). `npm run dev` · `npm run build` · `npx vite preview --port 4173`. Screenshots em `site/screenshots/`.
- `reel/` — Remotion 1080×1920, 20 s. `npm run render` (copia fotos de `assets/` e renderiza `out/yvoty-reel.mp4`, sem áudio) · `npm run frames`.
  **Final com trilha e master -14 LUFS:** `reel/out/yvoty-reel-final.mp4`.
- `assets/` — fotos (Antigravity/Gemini, ampliadas 2×; originais em `orig/`), `logo-yvoty.svg`, `music-yvoty.wav` (Pixabay, licença em `audio-src/LICENCA.md`).
- `brief/` — marca, copy da landing, roteiro do reel, prompts dos agentes.

Nada da SOL Internet neste projeto.
